# نظام إدارة المحلات التجارية المتكامل (Multi-Store ERP & POS)

نظام مركزي متكامل لإدارة ثلاثة محلات تجارية (بقالة، منظفات، حلويات ومستورد) بنظام نقاط بيع POS ومخازن ومشتريات ومصروفات وورديات وتقارير مالية وتكامل ذكاء اصطناعي (Gemini).

---

## 🚀 متطلبات التشغيل (Server Requirements)
- **Node.js**: الإصدار 18 أو 20 أو أحدث.
- **npm** أو **pnpm** أو **yarn**.

---

## 🛠️ خطوات التثبيت والتشغيل على الاستضافة

### 1. فك ضغط الملفات
قم بفك ضغط ملف `multi-store-system.zip` داخل مجلد موقعك على الخادم (VPS أو cPanel أو أي خدمة سحابية).

### 2. تثبيت الحزم والاعتماديات
```bash
npm install
```

### 3. إعداد متغيرات البيئة (.env)
قم بإنشاء ملف باسم `.env` في المجلد الرئيسي وضع فيه الإعدادات التالية:
```env
PORT=3000
NODE_ENV=production
GEMINI_API_KEY="ضع_هنا_مفتاح_جيميني_الخاص_بك"
```
*(مفتاح Gemini اختياري للملخص الصوتي الذكي وتحليل الصور والبحث في أسعار السلع، ويعمل النظام بشكل طبيعي وتلقائي بدونه).*

### 4. بناء المشروع للإنتاج (Build)
```bash
npm run build
```

### 5. تشغيل السيرفر (Start)
```bash
npm start
```
أو لتشغيل السيرفر في الخلفية بشكل دائم باستخدام **PM2**:
```bash
npm install -g pm2
pm2 start server.ts --name "multi-store-pos" --interpreter tsx
pm2 save
pm2 startup
```

## 🌐 خيارات الاستضافة المقترحة:
1. **استضافة VPS (Ubuntu / Debian)**:
   - مثل DigitalOcean, Hetzner, Contabo, Linode, AWS Lightsail.
   - تشغيل التطبيق مع Nginx كـ Reverse Proxy وشهادة SSL مجانية من Let's Encrypt.
2. **منصات سحابية بضغطة زر (One-Click PaaS)**:
   - **Render.com** (Web Service).
   - **Railway.app** (Node.js Service).
   - **Koyeb** أو **Fly.io**.
3. **استضافات cPanel**:
   - الدخول إلى قسم **Setup Node.js App**.
   - اختيار الإصدار 20، وتعيين ملف التشغيل `server.ts` أو `server.js`.

| :--- | :--- | :--- | :--- |

## 💾 قاعدة البيانات والبيانات المحفوظة
- يتم حفظ كافة البيانات (المنتجات، الفواتير، المخزون، الورديات، المصروفات، المشتريات) تلقائياً في ملف JSON مدمج سريع داخل مجلد `data/database.json`.
- الملف محفوظ ومحدث ذرياً (Atomic persistence) ولا يحتاج لأي إعدادات قواعد بيانات خارجية معقدة.
